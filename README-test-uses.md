✅ Overview of Test Types for This App

| Test Type             | What to test                                                                                                |
| --------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Unit tests**        | - Custom directive logic (`OnlyNumbersDirective`) <br> - Form calculation logic                             |
| **Integration tests** | - FormGroup working with the component <br> - Signals (`tipAmount`, `totalAmount`) updating based on inputs |
| **End-to-end (E2E)**  | - User fills form, selects tip, enters people count, sees correct output                                    |
